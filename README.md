A single Wi-Fi network name that tells a whole story in 32 characters: "My Ex Still Pays For This" — a breakup, an ex who still foots the internet bill, and a narrator smug enough to broadcast it to the whole building. Situation, character and event in one line, and none of the stock Wi-Fi jokes.

## Run it

```sh
python3 main.py
```

It writes the 25-character Wi-Fi name to `/output/entry.txt`. Standard library only, no network, no input files, and the same bytes on every run from any working directory.
